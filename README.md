## GitHub Pages deployment

1. Create a repository named `nithish-portfolio` under the GitHub account `nithishg-engineer`.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose **main** and **/(root)**.
6. Click **Save**.

Your portfolio URL will be:

https://nithishg-engineer.github.io/nithish-portfolio/

If you instead name the repository `nithishg-engineer.github.io`, the portfolio can use the shorter URL:

https://nithishg-engineer.github.io/
